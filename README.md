# ITCB · תוכנית תקציב שנתית

אתר לניהול התקציב השנתי של עמותת הבודקים (ITCB), במקום קובץ האקסל.

- `public/`: צד הלקוח (HTML/CSS/JS, בלי build)
- `netlify/functions/api.mts`: ה-API (התחברות עם מייל וסיסמה, משתמשים, שנים ושורות), והנתונים נשמרים ב-Netlify Blobs (`itcb-budget`)
- לשוניות לכל שנה: הכנסות · ריכוז הכנסות · ריכוז הכנסות בפועל · ריכוז הוצאות · ריכוז הוצאות בפועל · הוצאות · כמות נבחנים · רווח והפסד · הכנסות: תחזית מול ביצוע · מקור הכנסה: בפועל · מקור הכנסה: תחזית
- ייבוא וייצוא: אקסל (בפורמט התקציב) וגיבוי JSON

פריסה: `netlify deploy --prod` (אין שלב build).
